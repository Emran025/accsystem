# ADR-002: Separate browser UI and API
Status: proposed. Context: merchant workflow has browser UI and carrier integration. Alternatives: server-rendered monolith, SPA plus API. Criteria: team, deployment, security, complexity. Proposal: separate web and service containers for explicit trust/integration boundary; costs include added deployment complexity. Not approved. Affected: CNT-WEB, CNT-API. Reconsider after team and operational constraints known.
