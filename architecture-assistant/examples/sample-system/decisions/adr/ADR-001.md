# ADR-001: Select relational parcel store
Status: proposed. Context: shipment state has related entities and transactional updates. Alternatives: relational store, document store, managed service. Criteria: consistency, operations, cost, team. Recommendation: relational store; no approval or product selection yet. Trade-offs: schema discipline vs flexible documents. Risks/cost/operations require evaluation. Affected: CNT-DB. Reconsider after workload and operations review.
