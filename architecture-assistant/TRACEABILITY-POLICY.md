# Traceability policy

Registries, not prose search, determine coverage. Each child identifies a valid parent; maps explicitly connect context responsibilities to containers, containers to components, components to code structures, operations to functions, and decisions to affected elements. Exceptions are explicit map records, not missing arrays. Stable IDs are never recycled. Rename/split/merge/deletion is recorded in changelog and all links updated. Each element references its documentation and diagram paths where applicable. See registry schemas and validator.
