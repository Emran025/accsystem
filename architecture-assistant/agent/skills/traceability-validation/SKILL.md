# Skill: traceability-validation

Purpose: prove relationships and expose omissions.

## Procedure

Validate JSON registries and schemas; check uniqueness, parent IDs, child mappings, operation-function maps, ADR targets, local links, exceptions and diagram IDs. Run automated scripts and report actual result, blockers, unverified checks, coverage and exact missing IDs. Review semantic responsibility quality and renderer support explicitly as human/unverified checks.

## Required output

Provide evidence/source IDs, created/updated artifact paths, registry changes, gate result, unresolved facts and next-step recommendation.
