## 1. Identity

| Field | Value |
|---|---|
| **System ID** | SYS-ACMANAGEMENT |
| **Parent** | SYS-ACCECOSYSTEM |
| **Role in Ecosystem** | Web application providing two security-distinct zones: (1) a public portal for all visitors to browse ACC system catalog, releases, and download links; (2) a protected admin console for authorized users to manage platform licenses, platform users, and admin/support access. |
| **Scope Boundary** | ACManagement is a frontend client — it does NOT own any server-side business logic or databases. All backend functions are served by ACCSystem services (CNT-ACC-SOFTCAT, CNT-ACC-LICENSE, CNT-ACC-PLATFORMADMIN, CNT-ACC-IDENTITY). |

CONFIRMED (idea.md §2.1.1): "ACManagement منتج ويب مستقل من ناحية الواجهة وتجربة الاستخدام، ويتكون من منطقتين منفصلتين أمنياً."
CONFIRMED (idea.md §3.1.1): "ACManagement واجهة إدارة عامة ومحمية، بينما تتوزع وظائفها الخلفية على خدمات مستقلة."

## 2. Actors and Users

| Actor ID | Zone | Interaction |
|---|---|---|
| ACT-VISITOR | Public Portal | Browses ACC product/system catalog, views release notes, downloads installation packages |
| ACT-PLATFORM-ADMIN | Protected Admin Console | Manages platform users, grants/revokes admin privileges, issues and manages licenses, oversees platform operations |
| ACT-SUPPORT-STAFF | Protected Admin Console | Initiates scoped, time-limited support sessions under JIT authorization |
| ACT-INST-ADMIN | Protected Admin Console | May access institution-scoped license management within their institution scope (ASSUMPTION — scope to confirm) |

CONFIRMED (idea.md §2.1): "الزوار، مستخدمو المنصة، مسؤولو المؤسسات وفق نطاق الترخيص، مسؤولو المنصة وموظفو الدعم."

## 3. External Systems Consumed

None directly. Software package downloads are served from EXT-PACKAGE-CDN via signed URLs generated by CNT-ACC-SOFTCAT.

## 4. Connections to Other Platform Systems

| System | Direction | Protocol | Purpose |
|---|---|---|---|
| SYS-ACCSYSTEM (via CNT-ACC-APIGATEWAY) | Outbound | HTTPS/TLS | All public and admin API calls — software catalog queries, download link generation (IF-ACC-SOFTDL), license management, platform user management |

CONFIRMED (idea.md §3.1.1): "يجب أن تكون ACManagement واجهة عميل للخدمات الإدارية، لا أن تتجاوزها أو تتصل بقاعدة بيانات أي خدمة مباشرة."

## 5. Key Responsibilities

### Public Portal Zone:
- Display ACC system/product catalog — versions, release channels, platform requirements, release notes
- Provide download links for installation packages (signed URLs from CNT-ACC-SOFTCAT)
- No authentication required for public zone

CONFIRMED (idea.md §2.1.1): "منطقة عامة للزوار لعرض تعريفات أنظمة ACC والميزات والإصدارات ومتطلبات التشغيل وروابط التنزيل."

### Protected Admin Console Zone:
- License & entitlement management (issue, renew, suspend, revoke licenses)
- Platform user lifecycle management (activate, suspend, restore accounts; manage roles)
- Platform admin and support privilege management (MFA enforced, approval-based, JIT access)
- Support session initiation (scoped by institution, purpose, and duration)

CONFIRMED (idea.md §2.1.1, §7.7, §9): "منطقة محمية للمخولين لإدارة تراخيص المنتجات والمؤسسات، واستحقاقات الوحدات."

### Does NOT own:
- ACCore institution-local user management (ERP roles remain in ACCore) — CONFIRMED (idea.md §2.1.1)
- Identity & Access enforcement (delegated to CNT-ACC-IDENTITY) — CONFIRMED (idea.md §3.1.1)
- Software package binary files (at EXT-PACKAGE-CDN) — CONFIRMED (idea.md §3.1)
